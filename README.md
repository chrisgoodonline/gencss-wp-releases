# GenCSS for WordPress — Downloads

**[Download the latest release →](https://github.com/chrisgoodonline/gencss-wp-releases/releases/latest)**

The GenCSS design system generator, running inside the WordPress admin. Adjust
palette, typography, spacing, layout and components, and the plugin writes a
well-structured `globals.css` for your site — built on a two-layer token system,
primitives underneath and semantic tokens on top, so the whole theme changes by
remapping tokens rather than editing selectors.

## Installing

1. Download `gencss-wp-<version>.zip` from the [latest release](https://github.com/chrisgoodonline/gencss-wp-releases/releases/latest).
2. In WordPress, go to **Plugins → Add New → Upload Plugin**.
3. Choose the zip, install, and activate.

Updating is the same process — upload the new zip over the top. Your `globals.css`,
settings and licence are stored outside the plugin folder and are not touched.

There is no automatic update check; this plugin is not in the WordPress.org
directory. Bookmark this page and grab a new zip when you want one.
